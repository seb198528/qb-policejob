# qb-policejob - Police Job ULTIME pour QBCore

![Police](https://img.icons8.com/color/48/police.png)

## ✅ Fonctionnalités
- Menottage / Libération
- K9, SWAT, Drone, Hélicoptère
- Bodycam + intégration ps-mdt
- Talkie-walkie réaliste
- Badge "POLICE ACTIF" clignotant dans le HUD
- Système de permis (via qb-drivinglicense)
- Patrouille obligatoire

## 📥 Installation
1. Place le dossier dans `resources/`
2. Ajoute `ensure qb-policejob` dans `server.cfg`
3. Redémarre

## ⚠️ Dépendances
- qb-core
- qb-menu
- qb-target
- ps-mdt
- qb-clothing
- qb-hud (patché)
